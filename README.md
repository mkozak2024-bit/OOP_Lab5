# Лабораторна робота №5

## Тема
Основні парадигми ООП

## Мета роботи

Ознайомитися з основними принципами об'єктно-орієнтованого програмування:

- Інкапсуляція
- Наслідування
- Поліморфізм
- Абстракція

та реалізувати їх мовою Python.

---

## Інкапсуляція

Інкапсуляція дозволяє приховувати внутрішні дані класу та надавати доступ до них через спеціальні методи.

У роботі використано приватні атрибути:

```python
self.__balance
self.__attack_power
```

---

## Наслідування

Наслідування дозволяє створювати нові класи на основі існуючих.

У роботі класи:

- Sword
- Axe
- Bow

успадковують базовий клас Item.

---

## Поліморфізм

Поліморфізм дозволяє використовувати однакові методи для різних об'єктів.

Усі класи зброї реалізують власний метод:

```python
attack()
```

який працює по-різному.

---

## Абстракція

Абстракція реалізована через абстрактний клас:

```python
class Item(ABC)
```

та абстрактний метод:

```python
attack()
```
